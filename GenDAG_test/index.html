Abstract

Open text-to-image models struggle with requests that leave key content implicit or impose many explicit constraints. Multimodal agents can infer or retrieve this content and verify generated images, but for each request they must decide which operations to run and what information each one receives. We introduce GenDAG, an agentic framework that makes both decisions jointly by synthesizing a query-adaptive directed acyclic graph (DAG) whose edges carry typed intermediate results between operators. Before execution, a checker type-checks every edge and returns diagnostics for repair. After generation, visual checks against stated and inferred requirements guide regeneration. Using Qwen-Image-2.1 without fine-tuning, GenDAG scores 88.70 on WISE and 89.32 on T2I-CoReBench, exceeding direct generation with GPT-Image-2 and Nano Banana Pro, while trailing GPT-Image-2 by 1.51 points on GenEval2. Applied to GPT-Image-2, the same agent further improves the generation quality of this strong commercial model.
